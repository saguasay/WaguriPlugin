# Waguri GIF Plugin

A Revenge plugin that sends a random Kaoruko Waguri GIF when you type "waguri".

## How it works

When you type `waguri` in any chat and send it, the plugin intercepts the message and replaces it with a random Tenor GIF of Kaoruko Waguri from the anime *The Fragrant Flower Blooms With Dignity* (Kaoru Hana wa Rin to Saku).

## Installation

1. Open **Revenge** on your phone
2. Go to **User Settings** → **Revenge** → **Plugins**
3. Tap the **+** button
4. Enter the install link for this plugin
5. Done!

## Available GIFs

- Kaoruko Waguri (green dress)
- Kaoruko Waguri (pink dress)
- Waguri Kaoruko (blushing)
- Kaoruko Waguri (purple hair)
- Waguri Kaoruko (eating)
